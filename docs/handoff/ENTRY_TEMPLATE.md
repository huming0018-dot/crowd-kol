# 接力记录模板

每轮结束至少更新handoff日期、本轮结论与下一步；即使只读核对也写一行实际结果。每次主要改动后填写一条，追加到CHANGELOG.md；同步更新../HANDOFF.md受影响的当前状态与EVIDENCE.md。小改动可合并一轮记录，不复制整段对话。

## YYYY-MM-DD HH:mm TZ｜简短标题

- **接力者 / bot / 独立审查者**：
- **目标与范围**：
- **实际改动**（区分建议、文档、代码、数据）：
- **修改文件 / 组件 / 数据**：
- **版本**（仓库、分支、HEAD；未提交差异/包SHA/迁移/运行版本）：
- **验证**（时间、环境、输入、命令/方法、退出结果、PASS/FAIL/未跑；证据路径）：
- **独立审查**（范围、发现、修复、复核；不能作者自审冒充独审）：
- **部署 / 线上生效**（未部署也明确写；目标、版本、回读，不贴凭据）：
- **业务验收**（正文、评论分页、回复、媒体、导出、逐条回执；未验维度）：
- **风险 / 阻塞 / 下一步**：
- **可复核证据**：
- **状态更新位置**：

能力替换另记：同输入与账号/预算条件、旧/新执行器版本、字段差异、分页终止证据、媒体引用/字节区别、导出一致性、耗时/CPU/RAM/字节/人工操作对照、采用或否决理由。性能更快不能覆盖内容缺失。

读不到交接包、证据或某版本时，先注明缺口；不得写“已同步”。禁止粘贴密码、Cookie、token、私钥、连接串和私人邀请。
