# 媒体能力改进规则：从208实机失败到209

适用：采集插件、机器采集适配器、工作台和媒体处理。规则不改变原身份、回传、人工评价或OTA契约。

## 产品应交付什么

用户创建内容任务后，系统复用原持久登录，发现可取内容与媒体，选择成本最低且能满足用户目标的处理方式。独立字幕、语音文字、画面文字是三种结果：字幕轨有来源与时间，听写来自完整音轨，画面文字只代表指定区域采样。不能用后者填补前者的缺失后宣称全文完成。

## 开发与复用顺序

1. 先检查现有skill、固定依赖、平台原生能力与安装的开源源码。skill提供流程，不能把它的宣传或示例当平台保证。
2. 先看同一任务已取到的原响应，再看存储投影。没有保存某字段不能推出原响应没有该能力。
3. 原响应发现字幕后复用现有解析器；没有可靠格式适配就标记候选未验证，不以字符串路径猜测执行。字幕不存在、能力未支持、当前不是视频分别记录。
4. 先字幕、后完整音轨。目标策略：用户选择画面文字或原音轨缺失时提供画面文字选项，清楚标明用途；不隐藏成本与限制。209已将登记MP4默认改为语音转写；画面文字保留为明确选择，不能替代对白全文。
5. 已有视频直接注册来源引用，不先跑ASR、不复制大文件。已有解码PCM和模型在一个任务内复用；缓存键必须包含输入、模型、处理配置与实现版本。

## 从真实失败归纳的改进

- about:blank/提前停止：导航任务应把URL提交、tab创建、实际落地URL、登录与终止原因分别可见；首次验证应覆盖这些真实事件，不仅mock启动成功。
- 原协议字段：读取部署契约和脱敏真实响应后设计测试。来源动作admit/guard返回allowed=false即无来源动作许可，reason=null不能反推允许；control查询可返回allowed=false，不能据此阻止获准的activate控制动作。
- 音轨：检查实际流codec，不能把完整MP4或HTTP200当作有对白音轨；背景配乐不替代说话音频。
- 强制语言：非中文音轨可能生成中文猜测；自动检测是待同源验证的候选，不凭高置信值宣布准确。
- 幻觉/重复：原生logprob和no-speech值仅是提示。署名模板、重复短句、时间越界须单独观察；真实歌词/重复对白保留，不能全局去重。
- 专名：使用有来源的术语表和逐项不可变修订；标题不能当语音真值，也不能把相似字自动改成标题中的词。
- 识别边界：真实Vision矩形可略超边缘。保存native值及显式可见交集，不能因罕见数据误杀全部全文。
- 速度：先消除重复下载、先ASR注册、重复校验权重、首页读取全文等结构性浪费。一次小窗口速度不能外推所有长视频；保留完整性对照。
- UI：优先呈现可用结果、需要本人登录的原因、恢复状态和下一步，诊断明细按需展开。
- OTA：通过原签名渠道、保留回滚与真实握手；界面版本或包上传不证明原设备采用。

## 每项改进的验收

同输入对照记录wall/CPU/峰RSS、下载字节、来源请求、模型调用、用户操作次数及结果差异。保存失败样本和淘汰理由。文本导出逐段一致、云端save/get回取及原正文绑定独立复核；质量需要单独参考，云回执不等于语义质量。

保留原稿、原附件、来源封套、outbox、评分和已签更新。独审代理不参与该实现，记录源版本、真实验证范围、发现与复核。实验无收益或损害有效讲话时撤回，不堆叠未经实测参数。

## 208已证实与209待验证

208已证实：MLX单任务校验复用三窗结果一致且省时；B站有源专名修订另存；抖音及微博画面文字完整导出/云回取；直接已有文件省掉注册前ASR。未证实：七平台字幕阳性、所有幻觉消失、整体CER、并发P95或全长同质量倍率。209沿这些确切缺口继续，不降低交付口径。

## 209实机固化规则

- 来源不声明字幕时，复用已保存的完整音轨；不对标题、photo.caption或无时间的文案猜测。已覆盖五平台声明轨解析和任务/导出/云契约，但这不能替代五平台真实阳性样本。新快手、微博原会话小试均无声明轨。
- 本地Silero检测须检查全部窗口后才能提示“未检测到讲话”，结果是模型候选而非真值。保留原音轨和失败理由，并允许显式跳过检测；有效语音仍转写所有窗口，不删歌词或裁掉低置信词。
- 同源自动语言实验无质量收益，未接入。不能拿引擎置信度优化或高速空稿当改进。
- 不可变优化稿继承原音轨证明，不复制音轨/PCM。读取、导出、试听与云封套验证均追踪已验证父链；本轮真实子稿缺父证明读取错误已修复并补篡改/循环负例。
- 云查询的网络瞬断与未保存不同：只读查询可限一次重试，未知写入必须先对账，不能自动重发。界面给查询中、明确重查入口和当前回执。
- B站新全长31窗实际203.007秒、683段，与旧同源稿segments/诊断一致；优化另存681段，16项来源支持修改及2项真实重叠修订。四导出、云回取完成，不表示所有错字或专名已消除；全文语义仍待逐段核对。
