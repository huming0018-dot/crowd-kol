## 1. 产品承诺

交付一个能将分散来源持续转为可追溯领域数据的产品。Owner定义问题、范围、输出和预算；系统自动派单；参与者安装后尽量复用有效登录，在本机执行并耐久回传；材料经清洗、实体解析、评分与独立审计后，成为可查询、可导出、可反馈更新的发布快照。

首个消费者是上海美食发现；第二个复用验证优先使用已有 software-releases 包。采集器只是M1，不是整个交付。素材存在、云ACK、材料准入分、餐厅推荐、消费者采用是不同结果，逐级验收。

三条明确用户路径：
- Owner：三步建项目（范围/平台与模式/预算输出），随后看进行中、待处理、结果、设备。不手工分配HTTP请求或机器ID。
- 参与者：邀请安装、原身份接续、本人登录、自动领取、静默执行、回执评分、暂停恢复、自动更新。Cookie失效须可见；不能承诺永久登录。
- 消费者：搜索筛选/地图/详情与证据/收藏体验/纠错；反馈进入待审知识，不直接覆盖公共事实。

完整功能不删减：七平台及Pro扩展模式、KOL增量、根评论和回复分页、推荐/热搜、原媒体、字幕与全文听写、并发与账号池、断点去重、云回执、参与评分、OTA、M0–M7、分析与双领域复用。各平台不原生支持的模式明确显示，不用别的模式伪装完成。

## 3. 实现机制与接口闭环

Owner Manifest（问题/领域包pin/平台模式/预算/输出）
→ 中央任务与节点能力匹配（task/child/run/lease/epoch）
→ 原参与端或Pro引擎（会话引用，固定完整输入）
→ 本地保存及游标 + outbox耐久回传
→ 中央逐条ACK
→ capture快照转RAW（保留来源、原字段、ACK及partial原因）
→ 现M2清洗/实体证据
→ 现M3评分（rubric版本与缺分原因）
→ 现M6只读审计
→ 不可变发布快照与M7查询/页面/导出
→ M4知识提案、审核、新版发布、消费及回滚。

中央调度来源执行；toolbox jobs编排已取得材料。两者不相互重发未知外部操作。本地SDK保存屏障与云ACK屏障分开记录。去重分别处理任务幂等、节点epoch、来源内容版本、现实实体；不能把同店多份证据删成一条。

四类评分独立：材料证据准入、领域品质、Owner采集质量、参与者贡献奖励。缺食客/事实证据时是unknown/候选，不能为了完整演示填默认分。

逐步骤同时覆盖来源和处理：领取/会话/请求/页保存/媒体/outbox/ACK/检查点/终态，以及clean/score/audit/publish。字段、重试语义与错误分类沿 ARCHITECTURE.md，不新建平行协议。

## 5. 技术栈及外部复用的选择

- 数据内核：现Python>=3.12 toolbox、jsonschema/PyYAML、SQLite/既有PG接口。Pro保持自身Python>=3.11与锁文件，不强行合venv。
- 中央：现Supabase PostgreSQL/Edge/私有Storage；终端SQLite。平台凭据不进入领域包或发布快照。
- 终端/Owner：现Chrome MV3原生JS、Python工作台、Mac Swift更新助手。Windows/VM/手机分别验证；手机控制页不算手机本机采集。
- 消费：现toolbox Consumer与Next.js/React；只读发布DW/APP。现API缺口明确后才补路由，不先重写整套FastAPI后台。
- 媒体：现yt-dlp、ffmpeg/ffprobe、本地MLX/已接ASR；字幕/听写/OCR分型。
- ponytail(full)是开发约束：已有→标准库→已装依赖→最小完整改动。caveman是沟通约束；二者不是产品框架或调度技术。技能文件已实际读取，不声称界面hook已注册。

联网与独立推演分开记录，合并采用后才实施；详细15项复用卡见 RESEARCH.md。本轮刷新官方Pro能力、Scrapy分层、JSON Schema 2020-12与yt-dlp文档：
1. https://github.com/MediaCrawlerPro — 支持模式按平台核，组织页不是当前本地运行证明。
2. https://docs.scrapy.org/en/latest/topics/architecture.html — 借职责边界，不迁移第二套爬虫/调度器。
3. https://json-schema.org/draft/2020-12 — 新旧dialect显式兼容，不只改标签。
4. https://github.com/yt-dlp/yt-dlp — 复用字幕/skip-download/提取器，不等于所有视频都有字幕。

独立推演结论：最大收益是复用已采材料和成熟内核，减少重复请求/媒体下载/人工登录，而非继续添加框架。已有材料走F1A应0新平台调用；文字稿模式有字幕时目标0完整MP4下载；跨平台并发先1→2，以质量/错误/峰值资源为放行条件。具体阈值是待测目标，不是已达结果。
