## 0. 一句话设计哲学

我们的形态是「真人账号 + 真浏览器 + 真登录态 + 参与者可能还会同时手动使用」——检测面天然比 puppeteer/playwright 小一个数量级；**唯一需要认真做的是节奏**。所有节奏参数都是**抖动参数**：每次动作从分布里现抽，每台设备的分布参数本身也在装机时抖动一次——整个参与者的群体不存在任何两个相同的节奏指纹。

## 1. 检测面盘点：做什么与不做什么

| 维度 | 我们的形态 | 结论 |
|---|---|---|
| navigator.webdriver / headless / CDP / TLS 指纹 | 真 Chrome，全部天然正常 | **不用管**（stealth 工具拼命伪造的就是这些） |
| isTrusted 输入事件 | content script 无法伪造（规范级），chrome.debugger 可产生真事件但代价是"调试条" | **不伪造**。也不靠它——我们不模拟鼠标 |
| 行为轨迹（鼠标/滚动生物识别） | 不生成轨迹；参与者本人的真实使用混入采集会话 | **不做轨迹库**（文献证明伪造轨迹 >93% 可被神经模型识别，白费功夫） |
| 扩展特征指纹 | 小红书实测会弹"检测到风险插件"（按插件特征签名识别，非装了就封） | **隐身纪律**：不开 web_accessible_resources、不注入可见 DOM/样式、不碰全局命名空间、不改 UA |
| **行为时序统计** | ← 风控真正打分的地方 | **本稿的主战场** |

调研证据要点：小红书为多层防御（签名 JSVMP → 设备指纹 → 行为检测），可观察错误码 461/471=验证码、300013=频次异常、300015=环境异常；社区实测单账号单日 >300 条次日大概率弹验证码、约 300 条/会话触发频次异常；升级路径"先软后硬"，**手动过验证码后继续爬是灰名单进黑名单的实测路径**。来源见调研笔记。

## 2. 双层抖动参数模型（核心）

### 2.1 动作层：每次动作现场采样，不用固定值、不用均匀分布

所有间隔/时长用**截断对数正态**（truncated lognormal）——实证表明人类网页行为间隔服从 lognormal（UPC/Uni-Leipzig/BU 三组独立测量），重尾 + 爆发结构天然覆盖 Barabási 式"连点几下然后消失很久"的真人形态。

采样公式（逆变换截断，保分布形状、**不用 clamp**——clamp 会把概率质量堆到边界，反而成为特征）：

```
X = exp( µ + σ·Φ⁻¹( Φ_a + U·(Φ_b − Φ_a) ) )
其中 Φ_a=Φ((ln a−µ)/σ)，Φ_b=Φ((ln b−µ)/σ)，U~Uniform(0,1)
```

### 2.2 设备层：装机时一次性抖动分布参数（从 device_salt 确定性派生）

每台设备在首次运行时，用 device_salt 哈希出该设备专属的参数微调：

```
h_i = hash(device_salt, 参数名) → [-1, 1]
µ_device = µ_base · (1 + 0.12 · h_i)     // 中位数 ±12%
σ_device = σ_base · (1 + 0.10 · h_i)     // 散布 ±10%
时段画像、会话长度偏好同理（各 ±15%）
```

确定性派生 = 同一设备节奏长期稳定（真人特征），不同设备节奏互不相同（群体无共振）。参数存在 chrome.storage，服务端可下发收紧（沿用"只紧不松"合并规则），**永不放宽本地基线**。

### 2.3 动作参数总表（起步值 = 调研基线，全部运行时采样）

| 动作 | 分布 | 基准参数（µ/σ 为 ln 尺度） | 截断区间 | 依据 |
|---|---|---|---|---|
| 搜索间隔 | 截断 lognormal | µ=ln(90s)，σ=0.9 | [30s, 1800s] | HTTP 间隔 lognormal 实证 |
| 列表页停留 | 截断 lognormal | µ=ln(10s)，σ=0.8 | [3s, 90s] | 浏览快节奏实证 |
| 点开第几个结果 | 离散权重表 | 位置 1–10 ≈ [28,16,11,8,7,5,4,3,3,3]%；翻页 ≈1% | — | CTR 曲线实证 |
| 详情页阅读 | **二段混合**：30% 概率"甄别跳出"（µ=ln(6s)，σ=0.6，[2s,15s]）；70% 认真读（5s + 正文字数 ÷ 6.5 字/秒 + lognormal σ=0.5 噪声，[15s, 600s]） | — | — | NN/g 停留模型 + 中文默读 390 字/分（Brysbaert meta） |
| 详情页内滚动 | lognormal | µ=ln(12s)，σ=0.6 | [8s, 20s]/次 | ISLS 滚动间隔实证 |
| 详情→返回列表 | Bernoulli | p=0.15（没找到目标时 0.35） | — | Weinreich/Scaria 实证 |
| 单次会话动作数 | 逆高斯 µ≈3.7, λ≈2.7 | 截断 [1, 25] | 60%+ 为 1–5 动作短会话 | Huberman 冲浪定律 |
| 会话中休息 | 每 20–30 分钟插入 | 2–10 分钟，lognormal µ=ln(4min)，σ=0.7 | — | 工程惯例（SAide/WoW） |
| 会话间冷却 | 截断 lognormal | µ=ln(30min)，σ=1.2 | [5min, 6h] | Orkut 会话间隔实证 |
| 时段画像 | von Mises 混合 24h 曲线 | 每台设备固定；0–7 点 ≈0；12–13 点低谷 ×0.2–0.5；晚间高峰；工作日/周末两套；逐日 ±15% 抖动 | — | WWW2017 个体节律长期稳定实证 |
| 每日上限 | 硬上限 + warmup | 试点期 30–60 条/号/日；爬坡期第 1–3 天 30%、7 天到 100%；**硬上限 200 条/号/日**（社区实测 300 触发验证码） | — | waforge warmup + 风控实测 |
| 单次滚动次数 | 离散 | ≤25 次/页 | — | 风控调研 |

### 2.4 与现行 v3.3.4 基线的关系

现行基线（间隔 60–120s、会话 15min、冷却 30min、停留 ≥30s）**落在调研推荐区间内偏保守的一侧**——试点期维持现行值即可，v2 模型上线后作为各分布的"硬下限"保留（截断区间不变，分布变）。风控收紧时只改截断区间，不改分布族。

## 3. 链路真实性（比节奏更重要）

风控点名"跳过搜索直扫详情页"为异常链路。因此采集动作必须保持真人链路：

```
搜索（关键词）→ 列表页停留 → 按 CTR 权重随机选 30–60% 的笔记进详情
→ 详情页按字数阅读 + 滚动 → 15% 概率返回列表再看 → 采集该篇
```

禁止事项：拿 URL 清单直接批量开详情页；固定顺序逐个点开；列表零停留直接进详情。

## 4. 风控信号响应（状态机）

| 信号 | 动作 |
|---|---|
| 页面出现"访问频繁/验证" | **当日立即停止**，冷却 24–72h（lognormal 采样），全局记录 |
| 频次异常提示（300013 类） | 停止 + 冷却，且该设备次日配额减半 |
| 连续 3 次空结果/异常响应 | 暂停本轮会话，进入长冷却采样 |
| 一切正常 | 继续按分布走 |

**不做任何自动过验证码的能力**——既是账号安全（过验证后继续爬 = 进黑名单实测路径），也是合规叙事的核心证据（我们保护参与者账号，而非利用）。

## 5. 明确不做的事（调研证伪区）

- 伪造鼠标轨迹/滚动轨迹库（神经模型 >93% 可识别，且我们不需要）
- isTrusted hook / 指纹 spoof / 移植 puppeteer-stealth 思路
- 自动过验证码、自动换号、VPN/代理池
- 追求"逐信号零检测"——目标是落在真人分布内，不是隐形

## 6. 落地改造点（给你审的施工图，非代码）

`safety_engine.js` → 拆出三个模块：

1. `sampler.js`：截断 lognormal / 逆高斯 / 离散权重采样器（逆变换法，约 80 行）
2. `device_profile.js`：device_salt → 设备专属参数派生 + 时段画像 + warmup 状态机（持久化 chrome.storage）
3. `safety_engine.js` 改造：`canSearch/canViewNote` 等闸门返回的 waitMs 改为采样值；风控信号状态机并入

服务端：`safety_limits` 下发语义不变（只紧不松），新增"全局一键暂停"开关（风控调研建议）。移动端狐猴浏览器同包同模型，无需分支。

## 7. 验收方法

- **离线**：采样器单测（KS 检验对照目标分布；截断边界无堆积；1000 台虚拟设备参数两两不同）
- **试点观测**：首条风控信号出现时的累计采集量、账号健康率、每条采用成本——与 v3.2.3 时期基线对比
- **诚实边界**：中文 App 内详情停留无公开实证数据（参数由英文文献换算+试点校准）；CTR 来自英文搜索引擎，需自有埋点校准；小红书阈值动态调整，参数全部远程可收紧
